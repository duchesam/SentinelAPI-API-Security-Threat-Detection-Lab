# Optional Apigee adapter

Policy examples are supplied, not deployed or tested in Apigee. Replace the identity-provider placeholders and attach VerifyJWT to the request PreFlow with an appropriate fault handler. SpikeArrest smooths bursts; it is not a per-user quota. Add a Quota policy keyed to a verified identity for an actual allowance. Keep object-level authorization in FastAPI. Never treat a JWT validation policy as tenant authorization.
